# Esports Program GM Simulator

A no-login, single-file classroom simulator for planning an esports program from recruitment through a season reflection.

## Run it

Open `index.html` in a current desktop or mobile browser. The simulator has no build step, backend, account, or third-party runtime dependency. Student work is stored in that browser's local storage on that device and can be copied or downloaded from the reflection step.

## Flow

1. Recruitment plan and flyer
2. Training framework
3. Staff and support choices
4. Five-player roster selection
5. Season outcome simulation
6. Coach reflection and export

The season scoring is a simplified teaching model. Results are not a prediction of real team performance. `round2.html` and `round3.html` are retained as earlier design experiments; `index.html` is the primary simulator.
